# 🦠 COVID-19 Global Dashboard

An interactive **Power BI dashboard** for analyzing the global impact of COVID-19 using country-level and continent-level data.

## 📊 Dashboard Overview

The dashboard provides a high-level view of:

- Total COVID-19 cases
- Total recovered cases
- Total deaths
- Cases by country
- Cases by continent
- Geographic distribution of cases through an interactive map

## 🔍 Key Insights

Based on the dashboard shown in the project video:

### Global KPIs
| Metric | Value |
|---|---:|
| Total Cases | **~705M** |
| Total Recovered | **~560.6M** |
| Total Deaths | **~7.0M** |

### 🌍 Countries with the highest total cases
The dashboard shows the following countries among the highest totals:

1. USA — **111.82M**
2. India — **45.04M**
3. France — **40.14M**
4. Germany — **38.83M**
5. Brazil — **38.75M**

### 🌎 Cases by continent
The dashboard displays approximately:

- Europe — **253M**
- Asia — **222M**
- North America — **132M**
- South America — **70M**
- Australia/Oceania — **15M**
- Africa — **13M**

> **Note:** KPI cards are rounded in the dashboard, while country values are displayed with more precision.

## 📈 Visualizations

The report includes:

- KPI cards for global totals
- Interactive world map with country-level case distribution
- Country ranking table
- Continent-level comparison chart
- Drill-up / drill-down style interaction
- Interactive filtering and exploration

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query** for data preparation
- **DAX** for calculations and measures
- **Map visualizations** for geographic analysis

## 🎯 Project Goals

This project was created to practice and demonstrate:

- Data cleaning and transformation
- Data visualization
- Dashboard design
- DAX measures
- Geographic data analysis
- Extracting meaningful insights from large datasets

## 💡 Insights from the Dashboard

The visualization highlights the large geographic variation in reported COVID-19 cases. Europe and Asia represent the largest continental totals in the displayed data, while the USA has the highest country-level total shown in the dashboard.

The map also makes it easy to identify geographic clusters and compare the scale of reported cases across countries.

## 🚀 How to Use

1. Clone or download this repository.
2. Open the `.pbix` file using **Microsoft Power BI Desktop**.
3. Refresh the dataset if required.
4. Explore the interactive map, country table, and continent chart.
5. Use the available filters and drill interactions to analyze the data.
